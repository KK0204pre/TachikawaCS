# TachikawaCS - 立川市飲食店混雑状況確認システム

## 概要

TachikawaCSは、立川市内の飲食店の混雑状況を確認・共有できるWebアプリケーションです。

専門学校の卒業制作として5人チームで開発しました。

ユーザー登録をしなくても混雑状況の確認や投稿への評価、AI分析機能を利用でき、登録後は混雑情報の投稿も可能です。

## 開発背景・目的

飲食店を訪れる前に混雑状況が分からず、実際に店舗へ行ってから混雑に気づくという不便を解消したいと考え、チーム全員で話し合って開発テーマを決定しました。

特に、立川という身近な地域に着目し、飲食店を探す時間や待ち時間を減らすことを目的としました。

利用者が店舗を訪れる前に混雑状況を直感的に把握できるよう、地図上での混雑情報の表示や、情報の鮮度を保つ仕組みを取り入れました。

## 使用技術

- Python / Flask：バックエンド開発
- HTML / CSS：画面作成・デザイン
- JavaScript：動的な画面処理
- SQL / SQLite：データベース管理
- Leaflet / OpenStreetMap：地図表示

## 主な機能

### ログイン不要で利用できる機能

- 飲食店の混雑状況の確認
- 地図上での店舗位置・混雑状況の表示
- 混雑状況の色分け表示（緑・黄・赤）
- AI分析機能
- 投稿への評価機能（👍・👎）

### ユーザー登録後に利用できる機能

- ユーザー登録・ログイン
- 混雑状況の投稿
- マイページでの投稿履歴の確認
- 予約機能

### 混雑情報の有効期限

投稿された混雑情報が古くなった場合、実際の混雑状況と異なる可能性があるため、投稿から1時間を超えた情報を表示しない仕組みを実装しました。

これにより、利用者が比較的新しい情報を確認できるように工夫しました。

## チーム開発で工夫したこと

開発中は学校での対面での話し合いに加え、LINEやDiscordなどを活用して連絡を取り合い、定期的に進捗を共有しました。

各メンバーが担当機能を分担して開発を進める中で、実装に困っているメンバーがいた際には、互いに相談しながら問題の解決に取り組みました。

また、担当機能を統合する際に発生した不具合についても、メンバーと協力して原因を調査し、修正を進めました。

## 主体的に提案・改善したこと

### 1. 地図上での混雑状況の表示

飲食店の混雑状況を一覧の文字情報だけで確認するのではなく、店舗の位置と合わせて直感的に把握できるよう、地図上での表示を提案しました。

### 2. 投稿情報の有効期限の設定

古い混雑情報が残り続けると利用者が混雑状況を正しく判断しにくくなると考え、投稿から1時間を超えた情報を表示しない仕組みを提案・実装しました。

### 3. 投稿への評価機能

投稿された混雑情報に対して利用者が評価できるよう、👍・👎による評価機能を提案・実装しました。

### 4. 画面デザイン・操作性の改善

利用者が迷わず操作できるよう、画面の見やすさや投稿操作の分かりやすさを意識し、デザインや操作性の改善に取り組みました。

## 開発中に直面した課題と解決への取り組み

開発中には、プログラムのエラー、データベースへの保存・取得、画面表示の不具合、各機能の連携・統合などで問題が発生しました。

問題に直面した際には、デジタル教材や検索エンジンを活用して原因を調査し、必要に応じてチームメンバーと相談しながら修正を進めました。

また、自分の担当範囲だけでなく、ほかのメンバーが実装に困っている場面でも協力し、チーム全体で問題解決に取り組みました。

## 利用者目線で工夫したこと

利用者が飲食店の混雑状況を簡単に確認できるよう、以下の点を意識して開発しました。

- **直感的な表示：** 混雑状況を緑・黄・赤で色分けし、一目で把握できるようにした
- **地図との連携：** 店舗の場所と混雑状況を同時に確認できるようにした
- **情報の鮮度：** 投稿から1時間を超えた混雑情報を表示しない仕組みを導入した
- **情報の評価：** 👍・👎によって投稿を評価できるようにした
- **利用のしやすさ：** ログインせずに混雑状況を確認できるようにした
- **操作性：** 画面をシンプルにし、投稿操作を分かりやすくした
